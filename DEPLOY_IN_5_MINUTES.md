# Deploy Weight, What? in 5 Minutes (FREE)

## Option 1: GitHub Pages (Simplest - No Backend Needed)

1. **Fork or upload to GitHub**
2. **Go to Settings → Pages**
3. **Source: Deploy from branch (main)**
4. **Folder: /frontend**
5. **Save**

Done! Your site is live at: `https://yourusername.github.io/SizeComparator/simple.html`

## Option 2: Netlify Drop (Even Easier)

1. **Go to [app.netlify.com/drop](https://app.netlify.com/drop)**
2. **Drag the `frontend` folder onto the page**
3. **Done!**

Your site is instantly live with a random URL.

## Option 3: Surge.sh (Command Line)

```bash
npm install -g surge
cd frontend
surge
```

Choose a domain like `weightwhat.surge.sh`

## That's It!

- **No API keys needed**
- **No backend required**  
- **No monthly costs**
- **Works forever**

The `simple.html` file has everything built-in. It's just one file that works anywhere.

## Want to Customize?

Edit these in `simple.html`:
- Change the comparisons in the `comparisons` object
- Update the colors in the CSS
- Add more weight units in `conversions`
